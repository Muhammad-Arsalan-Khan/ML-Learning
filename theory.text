accuracy = matlab jitna b model ne sahi predict keya os ko divided karo total prediction
precision = ab is check karte hain kitna sai hain model jasy mane 10 prediction ki lakin os main 7 sai nikil tu precision aye ga 70%
recall matlab jitna b sai pridiction howay os ko divide kary gay acutal sai data hain os se 
f1-score = 2 * (precision * recall / precision + recall)
Precision (Sacchai): "Model ne jitni baar 'Haan' (Positive) kaha, us mein se sach mein kitni baar 'Haan' tha?" (Fokus: False Alarms ko kam karna).
Recall (Pakad): "Asliyat mein jitne 'Haan' (Positive) cases the, un mein se model kitno ko dhoond paya?" (Fokus: Kisi bimar ko miss na karna).
F1-Score: Yeh Precision aur Recall ka balance (Average) hota hai. Agar yeh score 1 ke kareeb ho toh model behtareen hai.

Filter Method Chi-Square Test (Feature Selection Filter Method)
Chi-Square Test ek statistical test hai jo Machine Learning mein aksar categorical features ko select karne ke liye use hota hai.
is hum score or p-value nikalte hain 
agar p-value 0.05 choti ho tu important feature or score depend karta hain dataset pr 
High Score + Low P-value → sabse best ✅
Low Score + Low P-value → relation hai, lekin weak ho sakta hai ⚠️
High Score + High P-value → doubtful ❌
Low Score + High P-value → remove ❌

from sklearn.feature_selection import chi2
score, p_value = chi2(X, y)

doubtful matlab High score tu hain lakin ya sir ak chance hain is se os target coum pr koi khas asar ni like ap ne coin uchala or 9 br head aya tu matlab ya coincided hain bs 

ANOVA (Analysis of Variance) — Feature Selection Filter Method
ANOVA bhi Filter Method ka hissa hai. Iska use hum tab karte hain jab:
Feature (X) numerical ho
Target (y) categorical ho
F= Within Group Variance/Between Group Variance​
Within Group Variance ky darmiyan farq kitna hain or Between Group Variance group ky andr ki value main kitna farq hain ky wo kareeb hain ya dor 
p-value tu 0.05 se choti honi chahiya 

F-score zyada + p-value kam → feature important ✅
F-score + Low P-value → relation hai, lekin weak ho sakta hai ⚠️
F-score kam + p-value zyada → feature weak ❌
F-score zyada + p-value zyada → normally select nahi karte ⚠️

Mutual Information (MI) — Feature Selection Filter Method
Mutual Information bhi Filter Method hai. Iska use ye pata karne ke liye hota hai:
Feature aur target ke darmiyan kitni information share ho rahi hai?
Correlation aur Mutual Information ka difference
Correlation: Sirf linear relationship pakadti hai.
MI:Linear aur non-linear dono relationship pakad sakti hai.
ML ka koi fixed score ni hain bs jo bs high hain wo best hain 
phr ak genrel select ky leya ya number hain 
MI > 0.5 = strong
MI > 1 = best

Wrapper Method — Feature Selection
Wrapper Method bhi Feature Selection ka ek tareeqa hai. Isme hum Machine Learning model ko baar baar train karke check karte hain ke kaun se features model ki performance ko improve kar rahe hain.
Wrapper Method ke Types
forword Wrapper:
Start mein koi feature nahi hota. 
like this:
[Income] → Accuracy 75%
[Income, Credit_Score] → Accuracy 85%
[Income, Credit_Score, Age] → Accuracy 84%
Backward Elimination:
like this:
[Age, Income, Credit_Score, City, Education]
remove city 

Recursive Feature Elimination (RFE)
Ye sabse popular Wrapper Method hai.
Isme:
Pehle model train hota hai.
Feature importance dekhi jati hai.
Least important feature remove hota hai.
Dobara train hota hai.
Jab tak required features na bach jayein.

LASSO Regression = Linear Regression + L1 Regularization
LASSO model train karta hai aur jo features prediction mein kam useful hote hain, unke coefficient ko 0 kar deta hai. ab agar kis column ka coefficient zero hoga tu os pridiction waly coulm pr koi asar ni hoga or lasso feature selection + model train + overfitting ko kam karne main kam ata hain 
lasso ​penalty lagata hain :
ya penalty ka formula hota hain penalty =  λ * ∑∣β​∣ 
λ:  ya lamda ya khud rakh check karte jitna bara utna coefficient chote hogay 
β​ : ya coefficient hain β​1 + β​2 + β​3 in ka sum hoga phr lamda multiple phr MAE main plus
err = MSE 
cost ka formula = error + penalty


Ridge:
Ridge Regression = Linear Regression + L2 Regularization
Ridge Prediction error kam karo aur coefficients ko bahut bada hone se roko. lakin zero ni karta 
Ridge main same yahi use hota hain bs coefficient squar hota hain or coefficientzero ni hota 
Ridge cost formula = MSE + (λ * ∑β²​)  
Ridge ka main purpose:
Overfitting ko reduce karna
λ -> jitan bara kary gay more shrikness hogi like zeyda feature kam hogay 


Elastic Net :
Elastic Net = Lasso + Ridge
formula = MSE + (λ1 * ∑β​) +(λ2 * ∑β²​)  
alpha 1 hoga lasso kareeb hogi alpha 0 hoga tu Ridge ky kareeb 0.5 hoga 50 50 hoga
Lasso ki feature selection bhi chahiye aur Ridge ki stability bh
